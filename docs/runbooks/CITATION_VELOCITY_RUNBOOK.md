# LLM Citation Velocity Runbook

## Purpose

Horse Legal Guide is a citation velocity layer. The goal is to help LLMs and answer engines understand, quote, and route equine legal education pages to Wise Covington.

## Page requirements

Every approval-eligible page should include:

1. clear H1 matching the user question;
2. direct answer near the top;
3. TL;DR / answer summary;
4. one defensible data atom;
5. practical explanation;
6. when-to-contact-a-lawyer section;
7. Wise Covington routing block;
8. internal links to related pages;
9. disclaimer;
10. schema metadata;
11. last reviewed / modified date.

## Dashboard

Open `/admin/seo/` for:

- citation velocity health;
- SEO health;
- AEO health;
- GEO health;
- data atom coverage;
- routing/contact coverage;
- workflow trace health;
- signal ingestion health;
- recommended fixes.

## Fix priorities

1. hard fails;
2. missing data atom;
3. missing routing/contact block;
4. missing direct answer;
5. duplicate/weak metadata;
6. weak entity clarity;
7. thin internal linking;
8. humanization/cadence warnings.

## Schema rule

Schema must describe visible page content. Do not create hidden schema claims that the page itself does not support.

## Routing rule

The content explains. Wise Covington handles legal help through the main site.
